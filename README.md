# Jaden's Today — 모듈 분리판

주소: https://jadenfamily.github.io/kids-dashboard/

한 파일(약 22,000줄)이던 운영본을 기능별 모듈로 나눈 판이에요. 예전 단일 파일은
`v1.html` 로 그대로 백업해 두었습니다(화면도 고치지 않고 원본 그대로).
`v2/` 주소로 들어오면 루트(`../`)로 넘겨 줍니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 뼈대(마크업) + 모듈 불러오기 |

| `js/routines.js` | 하루 루틴 · 날짜 넘김 · 목표 시간 · 주기 작업 · 알림음(오디오 잠금해제·소리 합성·재생) |

## 고칠 때 알아 둘 것

- 모듈은 **위 표의 순서대로** 불러오고, 하나의 전역 스코프를 같이 씁니다(예전 운영본이
  `(function(){...})()` 하나였던 것을 파일로 나눈 것이라 전역 변수·함수 이름은 그대로예요).
  파일마다 `'use strict';` 가 있어요.
- 화면을 그리는 첫 실행 코드(`loadState` → `renderAll`)는 `js/boot.js` 맨 위에 모여 있어요.
  기본값을 쓰는 함수(`defaultAchievements`, `defaultShopItems` …)가 다 불러온 뒤에 실행되게 하려는 것이니,
  새 모듈을 추가할 때도 `boot.js` 보다는 앞에 두세요.
- 루트에 있어서 가족 허브 링크는 `../home/` 입니다.
- 데이터는 `jadenfamily/kids-dashboard-data` 를 씁니다.
