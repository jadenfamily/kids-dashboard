# Jaden's Today v2 — 모듈 분리판

운영본 `../index.html`(한 파일, 약 22,000줄)은 **그대로 두고**, 같은 화면을 기능별 모듈로 나눠
A/B 로 써 볼 수 있게 만든 판이에요. 코드는 운영본과 같은 것을 줄 번호 순서대로 옮겨 담았고,
동작은 운영본과 같습니다(같은 `jadenfamily/kids-dashboard-data` 를 읽고 씁니다).

주소: https://jadenfamily.github.io/kids-dashboard/v2/

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 뼈대(마크업) + 모듈 불러오기 |

| `js/sync.js` | GitHub 비공개 저장소 불러오기/저장/병합 · 날씨 · 로그인·기기 연결 |
| `js/routines.js` | 하루 루틴 · 날짜 넘김 · 목표 시간 · 주기 작업 · 알림음(오디오 잠금해제·소리 합성·재생) |

## 고칠 때 알아 둘 것

- 모듈은 **위 표의 순서대로** 불러오고, 하나의 전역 스코프를 같이 씁니다(운영본이 `(function(){...})()`
  하나였던 것을 파일로 나눈 것이라 전역 변수·함수 이름은 그대로예요). 파일마다 `'use strict';` 가 있어요.
- 화면을 그리는 첫 실행 코드(`loadState` → `renderAll`)는 `js/boot.js` 맨 위에 모여 있어요.
  기본값을 쓰는 함수(`defaultAchievements`, `defaultShopItems` …)가 다 불러온 뒤에 실행되게 하려는 것이니,
  새 모듈을 추가할 때도 `boot.js` 보다는 앞에 두세요.
- `v2/` 는 한 단계 아래 폴더라 가족 허브 링크가 `../../home/` 입니다(운영본은 `../home/`).
- 데이터는 운영본과 같은 `jadenfamily/kids-dashboard-data` 를 씁니다. 같은 계정으로 로그인하면
  두 판이 같은 기록을 봅니다.
